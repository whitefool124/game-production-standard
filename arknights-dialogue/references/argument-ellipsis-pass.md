# 上一论辩的留白修订

用户指出不懂留白。旧稿将不甘、担心、对旧自己的维护全部解释，让读者察觉之前或刚察觉时就得到人物心理结论。此处修订不是要求今后删掉所有自述、缩短所有发言或用谜语代替明确思想。

原创补入共同看演出的经历。保留能判断的事实：阿岚在意布景结构，等换景并主动问人，提起不愿离厂却仍持续参与想做的事；出发令共同下次不确定。撤掉对这些事实的统一解释及作者结论。它不证明阿岚后悔、为家庭牺牲或认命，更不将站票强制解释为人生隐喻。长段与普通回答都可保留。

莉娅：“你说那家厂幸亏没离开，我记着呢。可每回有人来舰上演出，你都提前问哪天开场，站最后面也要看完。”
阿岚：“前排的票贵。站着也没什么，看布景又不用跟演员挤。”
莉娅：“你是去看布景的？”
阿岚：“不然？上回那座桥，远看挺像那么回事，船一过去，底下晃得厉害。我等着他们换景，想看看怎么搭的，灯却先灭了。”
莉娅：“原来你那天回来那么晚，是等这个。”
阿岚：“我还问了个搬东西的人。他说赶着拆场，没空理我。”
莉娅：“下次一起去，我提前买票。”
阿岚：“你明早就走，哪来的下次。”
莉娅：“等我回来，应该还有吧。”
阿岚：“不知道。他们不是常来的。”

未获用户验收。风险：短应答仍偏多；只覆盖旧自述的一处压缩，不代替充分哲学论辩。保留人物能直接说的关心和判断；依据场景判断哪个问题仍应答清，不将此次删解释变成新的全局禁令。
