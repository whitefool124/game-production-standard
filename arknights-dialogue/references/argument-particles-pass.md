# 同一片段：语气与习惯修订

方舟背景原创，人物与经历虚构。延续此前留白稿，加入语用差异，不改成给所有句尾填词。

莉娅：“你说那家厂幸亏没离开，我记着呢。可每回有人来舰上演出，你不都提前问哪天开场，站最后面也要看完？”
阿岚：“前排的票贵。站着怎么了？看布景，又不用跟演员挤。”
莉娅：“啊？你是去看布景的？”
阿岚：“不然呢？上回那座桥，远看挺像那么回事，船一过去，底下晃得厉害。”
阿岚：“我等着他们换景，想看看怎么搭的，谁知道灯先灭了。”
莉娅：“哦……难怪。我还以为你那天没赶上车，回来那么晚。”
阿岚：“我还找人问来着。搬东西的那个，一听就摆手，说赶着拆场，没空。”
莉娅：“下次咱们一起去吧，我提前买票。你别又一个人站后头。”
阿岚：“哎，你明早就走，哪来的下次。”
莉娅：“等我回来呀。应该还会有的吧？”
阿岚：“这可说不准。他们又不是常来的。”
