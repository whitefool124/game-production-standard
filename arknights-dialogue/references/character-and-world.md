# 人物、关系与世界

语气词与习惯句式的原文位置、关系变化及实际修订见 [语气与语癖](particles-and-habits.md)。不人手分配一个口头禅，也不把所有对白句尾补成啊/吧/呢；稳定习惯须随听者和情绪改变。

用于新角色设计、跨题材适配、同一人物多场景写作和角色同质检查。不是性格词与句式的配对表。

## 人物的稳定部分

从已有设定和行动建立人物，不用标签替代原因。只补当前场景需要的缺口：

- 想获得或保住什么；希望别人如何看待自己；这两者是否一致。
- 会先注意什么、凭什么判断：伤势、价钱、礼仪、声部、家人、退路，各有经验来源。
- 确信什么，又在哪些问题上缺乏经验。专业能力、社会判断和情绪承受力可不同步。
- 常用什么办法影响别人：解释、照顾、取笑、请求、讨价、命令、装糊涂。办法可以失败，也可以换用。
- 有哪些不肯公开的需求和不会轻易越过的界限；不要求人人都有创伤或秘密。

再处理词汇、句法、称呼、修辞和解释长度。人物职业影响他理解问题的方式，不能只贡献几个术语。艺术家可以对一处具体演奏细节敏锐，对现实事务幼稚；商人可以认真关心社区，仍计算合作利益。允许混合动机，不用一句台词宣布复杂性。

## 同一个人的不同说法

把稳定部分带进当前关系和压力中。对好友、上级、客户、后辈和敌人，不必说同一种中文。

面对上级可能先提交事实再提出异议；面对好友可能省略共同知识，先发牢骚再求助。熟人也可能因旧怨拒绝解释；陌生人未必冷淡。失去控制时，有人更啰嗦，有人转向细节，有人维持礼貌，有人直接求救。不要默认压力必然造成短句和省略号。

角色成长可以改变表达习惯，但应保留中间过程：能说出口不等于已想通，愿意合作不等于认同，不再服从也不必突然变得能言善辩。需要写同一人的过去和现在时，回读对应时间段，不能把后期经验放进早期人物。

复杂性要在行为里兑现。一个人嘲讽完后向别人要水，比介绍“他外冷内热”更有用；但不把每次刻薄都翻译成隐秘善意。有的人确实正在伤害别人。

## 背景进入对白的路径

先问背景究竟改变了什么：人物能做什么、要付什么代价、相信什么证据、觉得什么自然、哪些话不能当众说。若换掉所有地名和器具后因果毫无变化，这段可能只是装饰性设定；有些纯关系场景不需要突出世界，不能强塞设定来过检查。

| 背景因素 | 对表达与选择的影响 | 常见误写 |
| --- | --- | --- |
| 生计、资源与阶级 | 对时间、欠款、食物和机会的估价；接受或拒绝帮助的成本 | 穷人只愤怒，富人只傲慢 |
| 礼制、组织与权力 | 谁能问、拒绝、打断；恭敬是否真诚，是否用于封住异议 | 人人直接说真心话，或人人神秘迂回 |
| 地域、族群与历史 | 默认称谓、熟悉的比喻、误读与偏见；不同代际可能不同 | 用几句方言或古词替代文化 |
| 魔法、技术与身体 | 什么现象可信，谁有解释权，哪些操作危险，伤病如何限制说话 | 术语堆积，规则在需要时突然变化 |
| 信仰、寿命与记忆 | 对死亡、诺言、证言和未来的尺度；信仰可有日常实践 | 长寿者全说格言，信徒全狂热 |

现实、古风、奇幻、科幻等是适配方向，不是独立文风开关。古风人物可以粗俗、明白、做生意；科幻人物不一定冷硬；非人角色的感官和社会经验可有差异，但不要随便取消其个体欲望。已有世界规则优先，未给出的关键规则明确为独立样本假设。

## 少量可用的对照

以下是原创编辑例子，不是原作引文，也不是性格模板。

胆怯但有能力：他向贵客解释时容易退缩，被人碰到危险部件却能准确制止。不能忽然口吃就忘掉专业知识。

```text
“对不起，我得拆开看一下。您要是不方便等——别碰那根线！先把手拿开。不是外壳漏电，底下还接着另一个电源。”
```

讲究礼貌且有控制欲：礼貌不是修辞外壳，而是安排他人说话范围的办法。

```text
“当然，您可以拒绝。我只是想请您在拒绝之前，把费用由谁承担也告诉大家。后排那几位还不知道。”
```

亲近的人也有不相容的愿望：能理解理由，仍可能不接受决定。不要用一个漂亮的体谅句结束长期矛盾。

```text
“我知道你不想留。你不用再给我讲一次。可是你把她交给我照顾，再说走就走，我要怎么跟她解释？”
```

回读时检查整段的选择、关注点和关系是否一致；不要求每句遮掉姓名都能猜出角色。源作依据见 [adaptation-cases.md](adaptation-cases.md)。

《桥北》的实际失败表明：人物能做专业判断、各有政治愿望，仍可能只剩论题两端。用户希望看见偏好、性格和心情时，检查正文里有没有不止为解决主冲突而存在的个人生活：他爱什么、嫌什么，过去曾想做什么，熟人会怎样取笑或惹怒他，当下是兴奋、无聊、羞恼还是疲倦。这些应影响选择和说话，不按清单塞进一段履历。对白与心理共同让读者看见，而不是要求读者另读人设表才理解。

## 从本轮反馈固定的用法

用户对 [人物重写稿](bridge-north-voices.md) 评价“好一点了”。这是有限的正向反馈，不能推成整篇已优秀或所有场景已适配。可复用的是以下决策方法：

- **背景进入认识，而不只进入介绍。** 信号员从熟悉的桥声与反复操作形成过度自信；旧剧团经历影响贺宁用调侃缓解尴尬的方式。换职业后，应重新选择会注意的细节与会犯的错误，不沿用戏称与铁路术语。
- **偏好在关系里有后果。** 同一种糖，一个人喜欢、另一个人嫌难吃；熟人知道对方的习惯，仍可能劝错、惹烦。具体喜恶让关心有分寸，不需每个口味都藏象征，也不要求用糖、牌或旅行展示所有人物。
- **性格同时产生本事与麻烦。** 许岚好胜、爱纠正，既能及时指出危险，也会逞强、排斥被照顾；贺宁会应变和张罗，也会擅自替人做决定、拿好话绕开问题。不能只为好性格安排优点，再贴一个无实际后果的缺点。
- **稳定性格与即时心情分开写。** 嘴快的人受惊后仍可能先想到家里的杯子；会打趣的人数到失散孩子后也会收起笑。变化须由现场推动，不用统一的克制、冷静或沉重覆盖整场，也不为丰富强制安排情绪轮换。
- **个人愿望能与责任相冲突。** 贺宁想离开寒冷营地去看海，同时继续安置人；许岚曾想离开家乡求学，战后却不接受别人替她决定搬走。复杂性来自不同时期和不同需求的具体关系，不等于把人物写成反复无常。
- **一句话承载的情绪有对象。** 许岚不满别人只夸她恢复不易而不回答图画得对不对，羞恼与专业尊严因此可见；她肯认对方辛苦，仍可责怪他越过自己。避免让每句话都自我分析，关键处可以直接说清感受。

写完后，在正文中找证据，而不是再完善角色卡：有没有只有此人会注意的东西，有没有他说话时实际想获得的结果，有没有与当前主题不完全重合的生活。若证据缺失，修改发生的事和发言的理由；不要靠插入一段履历补交作业。逐句检查仍须连段进行，较长发言与自然衔接句都应保留。

## 强化六项对对白的实际作用

用户对临时学校搬迁、拆黑板的后续样本再次评价“好一点了”，并要求强化人设、背景、情绪、心情、偏好和性格。两次有限正向反馈保留，不扩大为已达到参考作品水平。以下为内部写作决策，默认不把表格交给剧情读者。

| 因素 | 改变什么 | 正文中的检查对象 |
|---|---|---|
| 人设 | 自我身份、关系位置、当前愿望与不能轻易放弃的部分 | 他认为自己有资格要求什么，怎样接受或拒绝别人赋予的身份 |
| 背景 | 默认知识、见过的代价、可信证据、比喻与解释路径 | 同一事实为什么在两人眼里不同，过去如何使此人判断过度或不够 |
| 情绪 | 对当前人物或事件的具体反应，及愿意暴露的程度 | 此刻究竟恼谁、怕什么、珍惜什么，措辞怎样变重、变软或停住 |
| 心情 | 入场时的整体状态、余裕与注意力，未必完全来自核心冲突 | 疲倦、期待、烦躁、舒畅等怎样影响耐心、听见什么及玩笑是否接得住 |
| 偏好 | 主动选择、喜恶、对细节的要求及关心的方式 | 不被剧情逼迫时仍会选什么；好意为什么可能不合对方口味或需要 |
| 性格 | 反复使用的应对方法与容易犯的错误，随关系和压力有所变化 | 他靠解释、强撑、取笑、安排还是求助影响人；办法如何成功或惹出麻烦 |

这些因素重叠，不是六个必须各有一条台词的栏目。人设不是头衔；偏好也不止饮食；心情不等于每场新加一种情绪；性格不保证同一人始终用同样长短的句子。

### 本轮可见的作用与尚存问题

许岚对画图和教学的偏好决定她在新校舍安排中关心什么：环境变好并没有取消她对课程价值的异议。未能求学、伤手和父亲旧日的苛刻共同影响她对“为你好”的理解。她可以认可搬迁有利、认真执行，仍不愿把专业尊严交给安慰。情绪因此有具体对象，而非泛泛的不舍家园。

贺宁的剧团生活使他想到房钱、卖票、班主与听戏的满足，不能只作为几句俏皮话的来源。他习惯照料与安排，又不完全懂教育，能提供经验而无需替许岚解出答案。想离开的愿望仍在，关心并不令它消失；此刻的轻松也会因许岚触及未被承认的东西而收敛。

这个样本仍有过多熟人接梗和及时理解的风险。强化作用时，不继续固定许岚负责挑错、贺宁负责接住的分工：同一个人可以先失去耐心，也可以误解对方，有时还会主动讲与听者兴趣不同的事。改变必须有情境依据，不为了人物丰富而随意翻转。

### 内部改写方法

先写出此人此刻想获得的结果和默认解释，再让其他因素改变关注、证据、措辞、句法、称呼、发言长度及回应。要点是能追踪的联系：背景造成何种看法，看法被什么触动，触动之后他怎样说和做；不要求按这一顺序写成正文。

拿具体台词做替换检查：若换成另一角色，只改名字就成立，检查是否缺少个人认识。普通确认与共同信息允许通用，不强迫每句独特。再换一个当下心情检查：如果兴奋与疲倦、期待与羞恼完全不改变听法和说法，可能只保留了静态性格。

修订要落实到正文。例如“别替我安排”仅陈述立场；说出课程表排除了什么、自己本来想教什么，以及父亲如今只敢问伤势，可以让同一个要求带上经历和情绪。这里不能被固化成学校、父亲、伤手或物件引回忆的模板，应随新人物与背景重建原因。
