# 常用字词局部改写与限制

针对已经交付的广播片段内部改写，非新的完整样本。保持原版不变，统计不混入这些改句。

## 次序表达：不只删先

旧：姓氏可以到车上再问。担架已经等在门外，先让人出来。

候选：门外的担架还空着。姓氏路上问，别让抬担架的人又跑一趟。

改变：把医师注意到的等待成本放到前面，而非连续宣布事情的办理次序。新增了再跑一趟的顾虑，不只是同义替换；需在整段检查是否确有这个行动成本。还、让、又均保留，它们现在说明持续等待、对方行为与重复劳动，不能为降频再删。候选也更急躁，须检查医师当时的耐心是否支持。

## 评价补语：改变听到的话，而非换近义词

旧：这话说得可不讨人喜欢。

候选：病人嫌一句茶凉了，还要听医师讲船上的人手。好，好，等上了船，我找你们厨房去。

改变：原先用一句泛评结束茶的争执；候选让抱怨继续有对象，保留广播员爱挑剔又希望受到照料的欲望，并非只给沉重回忆作铺垫。角色可能过于尖刻，增加找厨房的行动意向也须在后文保留或被打断，不能仅为丰富口气加一句随即消失的话。不是把得禁用，且没有证据要求其他评价句都重写成这样。

## 一词多功能：保留都、撤去过早的完满结果

旧：四十多年，隔着这块玻璃，谁要去哪儿，一张纸就讲清楚了。碰上字写得不好的，还要嫌人家耽误时间。

候选：四十多年，去哪儿，坐哪班车，都写在纸上。碰上看不清的字，就敲敲小窗，叫人重填；后面排着多少人，得等他写完了才知道。

改变：纸不再自动讲清一切，办理过程中有实际阻碍和迟来的认识；都用于列举共同范围，就仍是惯常条件动作，不因高频而删掉。后句增加了队伍等待及当事人办事经验，需确认旧广播员有兼管登记的经历，当前设定并未充分交代，因此此候选只能当未采用的方案。不能为了改句凭空补职业经历，正式成稿须改用既有广播工作的材料。

## 本轮未解决

局部词频变化无法判断全篇质量，第一处仍可能把医师写成持续催促者，第二处可能让老人的脾气变得过头，第三处改变了履历信息，暂不采用。统计的收获是暴露实际修改代价，而非把所有候选写进skill当正确范例。
