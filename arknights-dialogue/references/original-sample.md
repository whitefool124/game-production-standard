# 交接班

旧稿。用户反馈“AI 味道很重”，保留作失败对照，不再作为技能的推荐样本。问题与改写判断见 [naturalness.md](naturalness.md)。

独立原创样本。场景：一座沿海工业城的旧泵站即将封停。检修员许砚要争取撤离时间，厂务代表程隽负责执行封停。以下人物、地点和事件均为本样本创作。

泵站的时钟停在五点十七分。程隽抬腕看了一眼，把封停单放在配电柜上。

**程隽：** 六点之前，交回钥匙。

**许砚：** 哪一把？

**程隽：** 总闸。

**许砚：** 门钥匙可以先给你。总闸还得等一会儿。

**程隽：** 通知三天前就发了。

**许砚：** 昨晚涨潮，南巷的车没进去。今早才换了小车接人。

**程隽：** 调度表上写的是撤离完成。

**许砚：** 昨天下午填的。

程隽拨通调度室。电话里的人让他稍等，随后传来翻纸的声音。

**程隽：** 你有现场人数吗？

**许砚：** 四辆车，还差最后一趟。人数问司机。我从这儿只能看见巷口。

**程隽：** 大概多久？

**许砚：** 二十分钟。

**程隽：** 他们不能先走上桥？

**许砚：** 有两位老人搬不动。停泵以后水往巷里倒灌，小车也进不去。

**程隽：** 这台泵有二十分钟吗？

许砚没有立刻回答。他蹲下去，将扳手抵在轴承座上，另一端贴近耳朵。

**许砚：** 冷却水一直在漏。五分钟查一次，温度再升就停。

**程隽：** 你刚才只说要等。

**许砚：** 你也没问泵。

电话里终于有人应声。程隽听了一会儿，走到窗边。

**程隽：** 南巷还有人。对，把完成那一栏改掉。最后一辆车上桥以后，直接给我电话。

他挂断电话，拿起柜上的笔。

**许砚：** 他们同意了？

**程隽：** 他们让我按通知执行。

**许砚：** 那你改表干什么？

**程隽：** 免得下一班也照着错的办。

许砚擦掉压力表上的水汽。指针抖了两下，仍停在红线以内。

**程隽：** 延后封停这一栏，谁能签？

**许砚：** 你。背面第二条。

程隽翻过单据，看完那一条，又看了许砚一眼。

**程隽：** 你早看过了。

**许砚：** 三天了。总得看看。

程隽在延后原因里写下“撤离未完成”，签了名。他把单据递过去，没有放回漏水的柜面。

**程隽：** 运行记录归你。温度超限，马上停，不等我的电话。

**许砚：** 明白。

**程隽：** 门钥匙。

**许砚：** 你还要收？

**程隽：** 我去巷口。回来的时候，你得让我进来。

许砚从钥匙圈上卸下一把钥匙，递给他。

**许砚：** 右边那扇。左边的锁坏了。

程隽试着推了推右边的门。

**程隽：** 这扇也不太好。

**许砚：** 提着一点。别把钥匙拧断。

门开了。海风吹进来，掀起许砚手里的单据。他把纸夹进运行簿，拿起温度计，记下六点的读数。
