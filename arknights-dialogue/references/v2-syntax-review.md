# 跨稿的共同句法与交流骨架

用户指出译员片段句式单调，要求多写后自己分析。复核旧车站、阿岚长争执及上一译员段，并在商务交涉、学术争执和撤离中新写三段，再重写三段。原稿与修改保存在语料同级的skill-v2-2026-10-23/syntax-experiment.md。均为同一作者内部实验，无独立评审，未获用户认可。

## 重复在哪里

1. **先短判，再纠正，再说明。** 译员的“不是。手冷。”、阿岚争执的“我是在想我自己。”，以及新先稿连续用否定纠正对方，把每轮切成小结与解释。问题不在某一个不是/是，而是三种角色反复用同样方法管理对话。
2. **主语固定落在说话者与听者，谓语偏向知道、觉得、想、说。** 这些词必要时很自然，连续多轮却让正文成为彼此认识的说明。删掉代词而保留判断路径不会解决。
3. **反问负责转交论点。** 旧车站中围绕我们、死法与指挥官责任的逼问，阿岚段的能不能问，以及译员的名字/称呼/请求短问答，经常为下一段整齐备好入口。真正被问到的人却很少沿自己在意的部分继续。
4. **自述总以清楚回忆补足动机。** 经历一出现便准确解释眼前态度；句法上常为我以前如何、后来如何、所以如今如何。前后关系可以成立，几篇都靠它却会同声。
5. **叙述反复替对白放慢镜头。** 未开口、垂眼、手动一下、把物件捡起，常在情绪临界处依次出现。不是动作本身不准，而是所有高潮都被同一种停顿与细小动作导演。
6. **结尾习惯留一条可独立摘出的轻句。** 译员梨树的结尾、宣称以后不只要能干的自述，容易被作者预先安排成余韵。换成短句或普通物件不自动形成留白。

共同点不是错误的充分条件：稳定人物声音本来就需要重复，命令、纠正、问名也有实际任务。应查这些结构是否跨人物、关系、题材持续占据相同位置，并使说话总像同一个人在解释。

## 不新增事件的三处编辑试验

|原句|候选改法|实际改变及边界|
|---|---|---|
|我写申请比你还早，地点也填得清楚，偏偏——|申请交得比你早，连想去的地方都填好了，名单一贴，倒没我什么事。|将自我说明改为围绕申请与落选展开的抱怨；没有新设落选原因。末尾仍有抱怨落点，不应每句照此写|
|我也记得第一次按月拿到钱，放在兜里捂了一路，到家都没舍得拿出来。|头一回按月领钱，路上手就没离过那个口袋；到家还捂着，舍不得拿出来。|从宣告记忆转到当时的时间与动作持续，保留回忆内容；不能只把时间状语前置当句式丰富|
|芮恩没有开口。铅笔停在纸上，尖端压出一个小坑。|纸上被铅笔压出一个小坑。文森还在等，她却迟迟没有往下写。|读者先接到铅笔痕迹，再看到对方等待与记录停滞的关系；等待是现有交流的时间展开，不新添人物经历。被动句在此有对象重心，不全改主动|

这三处只证明能产生不同组织方式，不证明候选更好。它们与三场内容重构分开保存；避免通过加新惨剧、改救援结果来假称修复句式。

## 编辑时真正要改的层级

先找连续句子/轮次在重复做什么：是在判定对错、解释动机、追问缘由，还是在传递观察、修正范围、提出条件、列出证据、同时完成动作？确定当前内容需要哪一种展开，再比较信息顺序、主干、修饰从属、复句关系与停顿。不是依次分配一个倒装、一个排比、一个反问。

长句要能追踪语义重心，不用逗号把判定清单粘起来。短句可以有用，但连续短接球需要看其前后是否真的改变认识。语气词、口头禅和换称呼只能修声口，不能替代句法与发言路径。

原文对照可复用v2-cases中的hurt-pride和familiar-care：黑键在同一受辱短语上持续纠缠，白垩提供现实路径，发言不必逐点对齐；伊桑的敷衍、角峰对字面含义的坚持，使重复具有关系原因。两者也会用短问答与纠正，因此不从本次诊断推出全局禁令。

本轮联合报告在syntax-experiment目录：字词、层级长度、1—10档与局部位置保留；自动计数不识别完整中文句法。未做音频朗读，不宣称语感已经稳定。本轮不向用户交新样品作为验收答案。

实际结果：A1/A2均107字、句段均长均9.73，但二者短段比例54.55%/63.64%，相似均值掩盖不同局部构成；B1/B2扩为181/182字，不能把均长增加单归因于句式改善。A3→B3的短段比例81.82%→76.47%，危机中的短句仍占主导。六份的既有自动局部提示均为空，人工仍能识别前述共同骨架，说明现工具不覆盖此缺陷，不能据此称“检查通过所以无单调”。脚本保持其真实边界，本次不临时用脆弱正则制造语法通过分数。
