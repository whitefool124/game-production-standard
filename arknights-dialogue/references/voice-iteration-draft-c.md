# 外勤名单：第三稿

罗德岛背景原创，人物与经历虚构。内部候选，未获用户认可。

莉娅：“阿岚，我把箱子拿出来了。床底下那一层灰，你别看，我等会儿擦。”
阿岚：“我看它干什么？你都快把脸贴到我脸上了，怕我不知道你要走？”
莉娅：“那你知道了？”
阿岚：“名单在食堂门口，排队打饭的人都知道。明早七点集合，这回闹钟响了，你可真得起来。”
莉娅：“我今天中午都没睡。躺下去一闭眼，就是以前看的那家旅馆，窗帘是蓝的，窗户底下还有张小桌子。”
阿岚：“你还没忘？那张广告都卷边了。”
莉娅：“你说过，到那里先往浴缸里放热水，谁叫也不出去。现在真能去住，我反倒不知道怎么收拾箱子了，什么都想带，拿起来又觉得用不上。”
阿岚：“当然用不上，你把枕头都塞进去了，旅馆缺你一个枕头？”
莉娅：“那个硬。我上次值夜班，趴在柜子上睡醒，脖子疼了一整天。……你怎么知道是我枕头？”
阿岚：“拉链都合不上，露出半个角。你别硬拽，把衣服理一理，塞得到处都是。”
莉娅：“那你帮我看看。我以为你今天不会跟我说话了。”
阿岚：“不跟你说话，我晚上找谁借洗发水？不过我真有点不痛快。我写申请比你还早，地点也填得清楚，偏偏——”
阿岚：“算了。这会儿跟你说这个，你那点高兴又得收起来，留着等我哪天想开了再用。”
莉娅：“我没收起来。就是不敢在你面前笑。刚才一个人在走廊上走，玻璃里照见自己，嘴角翘得那么高，赶紧又抿下去了。旁边的人还问我，是不是牙疼。”
阿岚：“你怎么说？”
莉娅：“说没事。说完又笑了，人家已经走了，我还冲着人家的背影笑，自己也觉得傻。”
阿岚：“那点出息……枕头给我，压在底下试试。”
莉娅：“你没去成，我还这么高兴，是不是挺讨厌的？”
阿岚：“讨厌。尤其你一高兴就往我身边凑，躲都躲不开。我想清静一会儿都不成。”
阿岚：“可你要是在别处笑够了，回到屋里又对着我垂头丧气，那更没意思。我今天没选上，不至于连你是什么样的人都不知道了。”
莉娅：“……我想跟你一起去的。连那张桌子我都分好了，你坐靠窗的，我坐外面。”
阿岚：“我就非得靠窗？上次漏风的也是我那边。你回来先说说，窗子关不关得严，热水够不够，别光顾着给我夸景色。”
